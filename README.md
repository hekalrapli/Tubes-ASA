## Prasyarat

Pastikan sudah menginstal **Python 3.10** atau lebih baru. Cek versi Python:

```bash
python --version
```

## Cara Menjalankan
1. Clone repository ini, lalu masuk ke foldernya:

   **Clone via GitHub:**
```bash
   git clone https://github.com/hekalrapli/Tubes-ASA
   cd Tubes-ASA
```

2. Jalankan program:

```bash
   python main.py
```
